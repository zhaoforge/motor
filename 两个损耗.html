《电力系统分析》核心复习要点

功率本质 · 常用公式推导 · 变压器复功率损耗与电机学映射

最后压缩成的一条核心主线

电机学试验 空载试验 $\to$ 测铁耗 $P_0$ ；短路试验 $\to$ 测铜耗 $P_k$
等值电路 串联阻抗：$\Delta\dot S_T = I^2 Z_T$ ；并联励磁：$\Delta\dot S_0 = U^2 Y_T^*$
工程公式 $\Delta\dot S_T \approx \left(\Delta P_s + j\frac{U_s\%}{100}S_N\right)\left(\frac{S}{S_N}\right)^2$ ； $\Delta\dot S_0 \approx \Delta P_0 + j\frac{I_0\%}{100}S_N$
💡 一句话口诀：串联阻抗看 $I^2Z$，并联励磁看 $U^2Y^*$；再用短路试验和空载试验数据将它们换成实用公式。

瞬时功率定义：

\[ p(t) = u(t)i(t) \]

正弦稳态展开：

\[ p(t) = P + P\cos 2\omega t + Q\sin 2\omega t \]

其中：

\[ P = UI\cos\varphi, \qquad Q = UI\sin\varphi \]

物理意义剖析：

• $P$（有功功率）：能量的净传输，对应瞬时功率的非零平均值。

• $Q$（无功功率）：能量的往返交换，对应以 $0$ 为中心正负交替的交换功率分量的系数。

注意：不能简单说“$Q$ 是整个振荡功率的幅值”，因为振荡部分还包含 $P\cos 2\omega t$ 项。

复功率统一形式：

\[ \dot S = P + jQ \]

1. 纯电阻情况：

\[ P = UI\cos 0^\circ = UI \] \[ \text{代入 } I = \frac{U}{R} \implies P = \frac{U^2}{R} \]

2. 纯感性电抗情况：

\[ Q = UI\sin 90^\circ = UI \] \[ \text{代入 } I = \frac{U}{X} \implies Q = \frac{U^2}{X} \]
核心记忆： \[ P = \frac{U^2}{R}, \qquad Q = \frac{U^2}{X} \] 这两个是推导结果，其根源依然是本源定义：$P = UI\cos\varphi$ 与 $Q = UI\sin\varphi$。

教材在计算时实际严格划分为两部分：

1. 串联阻抗中的功率损耗：

\[ \Delta\dot S_T = \Delta P_T + j\Delta Q_T \] 2. 并联导纳（励磁支路）中的功率损耗： \[ \Delta\dot S_0 = \Delta P_0 + j\Delta Q_0 \]

结构与记忆规律：

• 串联 $\to$ 对应阻抗 $Z$ $\to$ 使用电流平方：

\[ \Delta\dot S_T = I^2(R_T + jX_T) \]

• 并联 $\to$ 对应导纳 $Y$ $\to$ 使用电压平方：

\[ \Delta\dot S_0 = U^2(G_T + jB_T) \]

这也是“一个用阻抗、一个用导纳”物理建模的本质由来。

原始形式：

\[ \Delta\dot S_T = I^2(R_T + jX_T) \] \[ \implies \Delta P_T = I^2 R_T, \qquad \Delta Q_T = I^2 X_T \]

• $\Delta P_T$：主要就是绕组的铜耗。

• $\Delta Q_T$：漏抗所吸收的无功功率，不是真正发热散失的能量损耗。

利用短路试验数据得到的实用工程形式：

\[ \Delta\dot S_T \approx \left( \Delta P_s + j\frac{U_s\%}{100}S_N \right) \left(\frac{S}{S_N}\right)^2 \]
这里的关键近似：

1. $X_T \approx Z_T$（高压变压器阻抗中电阻远小于电抗）

2. 实际计算中电压近似为额定电压：$U \approx U_N$

原始导纳与阻抗形式：

\[ \Delta\dot S_0 = G_TU^2 + jB_TU^2 \] \[ \implies \Delta P_0 = G_TU^2, \qquad \Delta Q_0 = B_TU^2 \]

换算成等效电阻、电抗并联形式为：

\[ \Delta P_0 = \frac{U^2}{R_m}, \qquad \Delta Q_0 = \frac{U^2}{X_m} \]

利用空载试验数据的工程实用公式（教材式 3.12）：

\[ \Delta\dot S_0 \approx \Delta P_0 + j\frac{I_0\%}{100}S_N \]

关键近似说明：

工程上采用 $S_0 \approx Q_0$，因为变压器励磁电流以建立磁场的无功分量为主。

严格公式应为：

\[ Q_0 = \sqrt{S_0^2 - P_0^2}, \quad \text{其中 } S_0 = \frac{I_0\%}{100}S_N \]

《电机学》是参数测定的底层物理来源：

• 空载试验： $P_0 = I_0^2 R_m$ $\to$ 主要测铁耗

• 短路试验： $P_k = I_k^2 R_k$ $\to$ 主要测铜耗

两门学科的关注视角递进：

• 《电机学》主要聚焦于设备本身物理上真正消耗掉的有功功率 $P$。

• 《电力系统分析》面向电网整体潮流与节点功率平衡计算，需要统筹平衡，因此把无功一并纳入统一的复功率损耗表达：

\[ \Delta\dot S = \Delta P + j\Delta Q \]

因此，“复功率损耗”里的 $\Delta Q$ 不是能量在物理意义上变热消失了，而是该元件在交流工作中所吸收/占用的无功功率。
